# Rüya dokuları

Hepsi [Poly Haven](https://polyhaven.com) kaynaklı, **CC0** (kamu malı).
`python assets/ruya/fetch.py` indirir, `assets/ruya/cc0/` git'e girmez.

| Kullanım | Varlık | Çözünürlük |
| --- | --- | --- |
| Ada duvarları, yakın kaya | [rock_face_03](https://polyhaven.com/a/rock_face_03) | 8K |
| Ada duvarları, büyük katmanlar | [cliff_side](https://polyhaven.com/a/cliff_side) | 8K |
| Ada üstü, uzak zemin | [aerial_grass_rock](https://polyhaven.com/a/aerial_grass_rock) | 8K |
| Ada üstü, yakın çimen | [leafy_grass](https://polyhaven.com/a/leafy_grass) | 8K |
| Yapılar, kesme taş | [large_sandstone_blocks_01](https://polyhaven.com/a/large_sandstone_blocks_01) | 8K |
| Ağaç gövdeleri | [pine_bark](https://polyhaven.com/a/pine_bark) | 4K |
| Çatılar | [clay_roof_tiles](https://polyhaven.com/a/clay_roof_tiles) | 4K |
| Ahşap kaplama | [weathered_planks](https://polyhaven.com/a/weathered_planks) | 4K |
| Bronz yüzey deseni | [rust_coarse_01](https://polyhaven.com/a/rust_coarse_01) | 4K |
| Geniş yaprak taçları (`leaves` haritaları) | [tree_small_02](https://polyhaven.com/a/tree_small_02) | 4K |
| İğne yaprak taçları (`twig` haritaları) | [fir_tree_01](https://polyhaven.com/a/fir_tree_01) | 4K |

Yüzey setlerinden renk (`diff`), OpenGL normal (`nor_gl`), AO/pürüzlülük/metal
(`arm`) ve yükseklik (`disp`) haritası kullanılır. Yaprak setlerinde yükseklik
yerine alfa (`alpha`) haritası gelir.
